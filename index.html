Touch: drag pans, pinch zooms, one finger orbits in 3D. Lines need a B (begin) — codes with no B stay points. BC…EC fits a constant best-fit-radius arc that passes exactly through every point (falls back to a smooth spline if the points don't fit a circle); add PCC/PRC at an interior point to start a new independent radius there (compound/reverse curve); offset lane lines through a curve get their own radius = that segment's radius ± the offset distance. OC fits a tangent arc between two tangent runs. CIR draws the full circle through 3 points. H/V + a value draw parallel offset lines (persist along the run). RBCB/RCFL curb codes (L624, R606…) auto-expand to the curb cross-section from the built-in template DB. RT/X/RECT + a value insert right-turn, extend, and rectangle vertices. RWLK1/2/3 are separate figures.

Quick start

      
    
        
  • ↥ Load FBK a field book text file (or ↥ Import CSV a comma-delimited PNEZD file — point#, N, E, Z, description). You can layer more than one import onto what's already loaded.
    • 
        
  • The canvas shows every point as a dot and draws linework for any figure code that has a B (begin) somewhere in the file — codes with no B stay plain, unconnected points.
    • 
        
  • Click a point (in SEL) to open the Inspector on the right — edit its N/E/Z, HA/SD/ZA, rod height, or descriptor code there; edits reflect live on the canvas and in Review/edit FBK code (the CODE tag on a selected line).
    • 
        
  • Click a line (not a point) to open the figure editor — reorder vertices, jump/zoom to one, insert a point on the line, walk it in Street View, or render it as plain NEZ coordinates on export.
    • 
        
  • ⚙ Knockdown bakes curb codes (see the Curb Database tab) into real H/V offset coordinates. 🧭 UGW→CPN pairs guy wires to their nearest pole with an editable review before applying — both are one-click bulk operations, run them once your points look right.
    • 
        
  • When you're done, ↓ Export FBK writes a field-book file back out (or ↓ Export (codes) to keep the original curb-code names instead of baked offsets, or ↓ Export CSV for a plain PNEZD coordinate file).
    • 
        
  • ↶ Undo / ↷ Redo (Ctrl+Z / Ctrl+Y) cover every edit — point moves, code changes, deletes, Knockdown, UGW→CPN, and inserts.
    • 
      

      
Views

      
    
        
  • Plan (2D) is the default — pan/zoom/edit view, north-up.
    • 
        
  • 3D (⟲ Orbit) shows the survey by elevation — drag to orbit (it re-centers on whatever you click, so a far corner of a large site orbits smoothly instead of swinging wildly), wheel to zoom toward the cursor, Shift-drag or middle-mouse-drag to pan, and the VERT EXAG slider exaggerates elevation differences. ⊡ Fit always resets to the whole-survey view. Clicking a point or line opens the same editable Inspector/figure editor as 2D — only dragging to move a point, and clicking to insert a brand-new one, still need a 2D tool.
    • 
        
  • 🗺 MAP toggles an aerial imagery background (2D only) — county imagery with an Esri/USGS fallback chain.
    • 
        
  • 🏷 Labels lets you choose whether each point shows its number, code, elevation (any combination) and at what text size.

Mouse & touch

      

        
Left dragTool-dependent: box-select in SEL, orbit in 3D, pan in PAN, box-zoom in WIN.

        
Middle dragPan, in either the 2D or 3D view, regardless of the active tool.

        
Shift-dragPan while in 3D orbit (an alternative to middle-drag); Shift/Ctrl-drag in SEL adds to the current box selection.

        
WheelZoom toward the cursor (2D and 3D alike).

        
TouchDrag pans, pinch zooms, one finger orbits in 3D.

        
Del / BackspaceDelete the current box (multi-)selection.

        
EscCancel whatever pick/pan/insert is in progress, or clear a box selection.
