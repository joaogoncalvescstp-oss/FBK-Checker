SEL edits the descriptor code that drives linework, or deletes a shot. Drag a box on empty canvas to select many points (Shift-drag adds; Delete removes).
3D orbits the survey by elevation — click a point or line to edit its fields right here in the Inspector, same as 2D; only dragging to move a point or clicking to insert a new one still need a 2D tool. Orbiting re-centers on whatever you click, so a far corner of a large site orbits smoothly too; press ⊡ Fit to recenter on the whole survey. Middle-mouse-drag pans.

Edits 0

Touch: drag pans, pinch zooms, one finger orbits in 3D. Lines need a B (begin) — codes with no B stay points. BC…EC fits a constant best-fit-radius arc that passes exactly through every point (falls back to a smooth spline if the points don't fit a circle); add PCC/PRC at an interior point to start a new independent radius there (compound/reverse curve); offset lane lines through a curve get their own radius = that segment's radius ± the offset distance. OC fits a tangent arc between two tangent runs. CIR draws the full circle through 3 points. H/V + a value draw parallel offset lines (persist along the run). RBCB/RCFL curb codes (L624, R606…) auto-expand to the curb cross-section from the built-in template DB. RT/X/RECT + a value insert right-turn, extend, and rectangle vertices. RWLK1/2/3 are separate figures.

Restore auto-saved work

    

      Copies of your work saved in this browser after each change (last 5 jobs).
      Restore loads the job as it was at that time. They stay only on this computer and
      browser — Export FBK is still your real copy.
    

    

    

      
    

  






  

    
Duplicate Point Numbers

    

      A repeated point # is usually normal (face 1 + face 2, repeat sets, the same point
      re-shot from another setup) and is left alone. Only a # used for two different
      things is listed as a real duplicate: the control point (or the first in file order)
      keeps the number, the others get the next free number (renamed together with their
      face pair). Edit it if you want, or tick Delete. Nothing changes until Apply.
    

    

    

    

      
      
      
    

  






  

    
Coding Check Before Export

    

      Codes that take a number — H/V offsets, RT/X/RECT,
      CPN/RPN, curb codes like R624 — need a space on both sides, or the app and CAD can't read them.
      Missing space after the number: H-0.5V0.0, CPN9124B, R624BC.
      Missing space before the code: BV0, R624H-0.5, ECPN001, BCR624.
      Ticked rows get the space added. Untick a row to leave it as typed.

Knockdown — Review Needed

    

      Each point below needs a decision before it can be knocked down: either
      it carries its own curb code AND has a REF point within range (pick
      Standard or REF), or it has NO code of its own and the code carried
      forward from an earlier point disagrees, side (L/R), with the nearest
      declared code (pick which one is actually right for this point). Every
      other point (no ambiguity) knocks down normally alongside these once you
      Apply.

Quick start

      
    
        
  • ↥ Load FBK / JOB a field book text file — or a Trimble Access .job file, which is decoded, reduced to coordinates and loaded as an FBK (📂 Job then shows its points, station setups and notes) (or ↥ Import CSV a comma-delimited PNEZD file — point#, N, E, Z, description). You can layer more than one import onto what's already loaded.
    • 
        
  • The canvas shows every point as a dot and draws linework for any figure code that has a B (begin) somewhere in the file — codes with no B stay plain, unconnected points.
    • 
        
  • Click a point (in SEL) to open the Inspector on the right — edit its N/E/Z, HA/SD/ZA, rod height, or descriptor code there; edits reflect live on the canvas and in Review/edit FBK code (the CODE tag on a selected line).
    • 
        
  • Click a line (not a point) to open the figure editor — reorder vertices, jump/zoom to one, insert a point on the line, walk it in Street View, or render it as plain NEZ coordinates on export.
    • 
        
  • ⚙ Knockdown bakes curb codes (see the Curb Database tab) into real H/V offset coordinates. 🧭 UGW→CPN pairs guy wires to their nearest pole with an editable review before applying — both are one-click bulk operations, run them once your points look right.
    • 
        
  • When you're done, ↓ Export FBK writes a field-book file back out (or ↓ Export (codes) to keep the original curb-code names instead of baked offsets, or ↓ Export CSV for a plain PNEZD coordinate file).
    • 
        
  • ↶ Undo / ↷ Redo (Ctrl+Z / Ctrl+Y) cover every edit — point moves, code changes, deletes, Knockdown, UGW→CPN, and inserts.
    • 
      

      
Views

      
    
        
  • Plan (2D) is the default — pan/zoom/edit view, north-up.
    • 
        
  • 3D (⟲ Orbit) shows the survey by elevation — drag to orbit (it re-centers on whatever you click, so a far corner of a large site orbits smoothly instead of swinging wildly), wheel to zoom toward the cursor, Shift-drag or middle-mouse-drag to pan, and the VERT EXAG slider exaggerates elevation differences. ⊡ Fit always resets to the whole-survey view. Clicking a point or line opens the same editable Inspector/figure editor as 2D — only dragging to move a point, and clicking to insert a brand-new one, still need a 2D tool.
    • 
        
  • 🗺 MAP toggles an aerial imagery background (2D only) — county imagery with an Esri/USGS fallback chain.
    • 
        
  • 🏷 Labels lets you choose whether each point shows its number, code, elevation (any combination) and at what text size.
    • 
        
  • Reorder a line by clicking: in the line editor click 🔢 Pick order on map, then click the line's points on the map in the order you want — it applies once all are picked (or Apply now keeps the rest after your picks). Click a picked point again to back up to it; Esc cancels.
    • 
        
  • Moving panels: every pop-up dialog drags by its title bar, and the tool column (⠿ grip), legend, OSNAP box, Labels box and 3D VERT EXAG bar (⠿ grip) drag anywhere in the drawing area. Double-click the title/grip to put it back. The 📜 FBK code panel drags by its header.
